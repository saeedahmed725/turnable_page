Realistic page flip for Flutter

Turnable Page is a page curl widget for flipbooks, e-books, magazines, catalogs, Quran and manga readers, and PDF viewers. Every page is a normal Flutter widget, so buttons, text fields and lists keep working.

flutter pub add turnable_page

Installation

Add the package to pubspec.yaml:

dependencies:
  turnable_page: ^2.0.0

Then import it:

import 'package:turnable_page/turnable_page.dart';

Turnable Page needs Dart 3.8 or later. It works on Android, iOS, web, Windows, macOS and Linux.

Quick start

Give TurnablePage a page count and a builder. The builder is called with the page index and the size available for one page.

class BookScreen extends StatelessWidget {
  const BookScreen({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: Center(
        child: TurnablePage(
          pageCount: 10,
          pageViewMode: PageViewMode.auto,
          builder: (context, pageIndex, constraints) {
            return ColoredBox(
              color: Colors.white,
              child: Center(child: Text('Page ${pageIndex + 1}')),
            );
          },
          onPageChanged: (leftIndex, rightIndex) {
            debugPrint('Showing $leftIndex / $rightIndex');
          },
        ),
      ),
    );
  }
}

Drag a page or tap it to turn it. The book fills its parent as far as it can while keeping its aspectRatio, and stays centered.

Page layout

pageViewMode picks how many pages are visible at once.

ModeBehavior
PageViewMode.singleOne page at a time. This is the default.
PageViewMode.doubleA two-page book spread, with a spine in the middle.
PageViewMode.autoOne page when the book is under 600 px wide, two pages from 600 px. It switches live when the window is resized.

Covers

In a spread, FlipSettings(showCover: true) shows the first and last pages alone, like the covers of a hardcover book.

TurnablePage(
  pageViewMode: PageViewMode.double,
  settings: FlipSettings(showCover: true),
  pageCount: 12,
  builder: buildPage,
)

Size

aspectRatio is the width divided by the height of one page. It defaults to 2/3. In a spread, the book is twice as wide.

Controller

A PageFlipController turns pages from code and reads the book's state.

final controller = PageFlipController();

TurnablePage(controller: controller, pageCount: 20, builder: buildPage);

// Animated: completes when the turn ends.
await controller.nextPage();
await controller.previousPage();
await controller.animateToPage(7);
await controller.animateToFirstPage();

// Instant.
controller.jumpToPage(3);
controller.jumpToLastPage();

// State.
controller.currentPageIndex; // 0-based
controller.pageCount;
controller.hasNextPage;
controller.hasPreviousPage;
controller.hasClients;       // true once a book is on screen

Before a book is attached (hasClients is false), getters return neutral values and navigation returns false instead of throwing. You can pass a new controller to a book that is already on screen.

nextPage, previousPage and animateToPage take an optional FlipCorner.top or FlipCorner.bottom to choose which corner the page is lifted from.

Events

For page changes, onPageChanged is usually enough: it is called once with the new pages when a turn completes. For more detail, listen to the controller once the book is attached.

controller.addEventListener(PageFlipEvent.flip, (event) {
  final newPage = event.data as int;
});

controller.removeEventListener(PageFlipEvent.flip);

Gestures and taps

Pages turn by dragging, by flinging, or by tapping. These settings control how the book reacts to the user's finger.

Tappable page content

By default, a tap on an empty part of a page turns it, and the corners are reserved for turning, so taps there never reach your widgets. If your pages have links, buttons or verses near the edges, turn tap-to-flip off:

TurnablePage(
  settings: FlipSettings(flipOnTap: false),
  pageCount: 604,
  builder: buildPage,
)

Taps then always go to the page. Pages still turn by dragging, from anywhere including the corners, and from the controller.

Drag direction

In single-page mode, the turn direction normally depends on where the finger lands: the left 40% of the page means "previous". With directionFromDrag: true, the direction comes from the drag instead. Dragging right to left turns forward and left to right turns back, wherever the finger landed. This is mirrored for RTL books.

Grabbing the page

keepGrabOffset (on by default) keeps the spot you grabbed under your finger, so pulling a page from the middle of its edge gives a natural curl. Turn it off to have the page corner jump to the finger, as in 1.x.

Flings and thresholds

  • enableInertia: a fast fling finishes the turn even before the page passes the middle. inertiaVelocityThreshold sets the release speed, in px/s, that counts as a fling.
  • cornerTriggerAreaSize: the size of the corner hot zone, as a fraction of the page diagonal.
  • onlyVerticalPageFlip: turn pages with vertical drags only.

A short drag that does not reveal enough of the next page is cancelled, and the page falls back into place.

Scrolling inside pages

A page can contain a ListView or SingleChildScrollView. The book decides from the first movement of the finger: a mostly vertical drag scrolls the page, and a mostly horizontal one turns it. swipeAngleThreshold sets how much more horizontal than vertical the drag must be to turn the page (default 1.25).

Pinch-to-zoom

TurnablePage(
  enableZoom: true,
  minScale: 1.0,
  maxScale: 3.0,
  pageCount: 10,
  builder: buildPage,
)

While a page is zoomed in, dragging pans it instead of turning it. Zoom back out to turn pages again.

Double tap

By default, a double tap zooms in to 2x, and a second double tap zooms back out. To use double tap for your own gesture, such as showing the reader's toolbar, turn it off and keep pinch-to-zoom:

GestureDetector(
  onDoubleTap: toggleToolbar,
  child: TurnablePage(
    enableZoom: true,
    enableDoubleTapZoom: false,
    pageCount: 10,
    builder: buildPage,
  ),
)

From code, controller.isZoomed tells whether the page is zoomed in, and controller.resetZoom() zooms out.

PDF viewer

TurnablePdf opens a PDF document as a flipbook. Initialize the PDF engine once, before runApp:

Future<void> main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await TurnablePdf.initPDFLoaders();
  runApp(const MyApp());
}

Then pick a source:

// Bundled asset (declare it under flutter/assets in pubspec.yaml)
TurnablePdf.asset('assets/catalog.pdf', pageViewMode: PageViewMode.auto);

// Network, with optional HTTP headers
TurnablePdf.network(
  'https://example.com/magazine.pdf',
  headers: {'Authorization': 'Bearer $token'},
);

// Local file path
TurnablePdf.file('/storage/emulated/0/Download/book.pdf');

Loading and errors

TurnablePdf.network(
  url,
  loadingBuilder: (context, source) => const Center(child: CircularProgressIndicator()),
  errorBuilder: (context, title, message, onRetry) => Center(
    child: TextButton(onPressed: onRetry, child: Text('$title. Retry')),
  ),
);

Without builders, a shimmer is shown while loading and an error card with a retry button on failure. PDF rendering uses pdfrx.

Right-to-left books

TurnablePage(
  textDirection: TextDirection.rtl,
  pageCount: 604,
  builder: buildPage,
)

Page 1 is on the right and pages turn from left to right, like an Arabic or Hebrew book. Leave textDirection as null to follow the ambient Directionality. Gesture settings such as directionFromDrag are mirrored automatically.

Book frames

paperBoundaryDecoration draws a frame around the book. Use a preset:

PresetLook
PaperBoundaryDecoration.vintageLayered warm borders. Default for TurnablePage.
PaperBoundaryDecoration.modernA clean border with a soft shadow. Default for TurnablePdf.
PaperBoundaryDecoration.parchmentAged paper tones.
PaperBoundaryDecoration.noneNo frame.

Or build your own from a few high-level values:

TurnablePage(
  paperBoundaryDecoration: PaperBoundaryDecoration.custom(
    baseColor: const Color(0xFFF4EBDD),
    shadowColor: Colors.brown,
    borderRadius: 6,
    borderWidth: 0.8,
    shadowOpacity: 0.25,
  ),
  // ...
)

Set pagesBoundaryIsEnabled: false to hide the frame without changing the decoration.

Shadows and paper

FlipSettings(
  drawShadow: true,
  showCenterShadow: true,          // spine shadow in a spread
  centerShadowColor: Colors.black,
  innerShadowColor: Colors.black,  // inside the fold
  outerShadowColor: Colors.black,  // cast on the page below
  perimeterShadowColor: const Color(0x3D000000),
  perimeterBorderColor: const Color(0x1F000000),
  maxShadowOpacity: 0.8,
  hideLeftShadow: false,
)

Dark mode

pageBackgroundColor is the paper painted under pages, on the back of a turning page, and on blank filler pages. It is white by default. If your pages are dark, set it to their color, or light edges flash during a turn:

FlipSettings(pageBackgroundColor: const Color(0xFF1E1E1E))

The thin border around the back of a turning page (pageBorderColor) is derived from it: slightly darker for light paper, and no border for dark paper.

Curl shape and feel

  • flippingTime: turn duration in ms (default 700).
  • enableEasing: eased motion for turns started from code or a tap.
  • sagAmplitude: how much the fold line sags, as a fraction of the page height. 0 gives a straight fold.
  • bendStrength: how strongly the paper bends, from 0 to 1.

Large books

Only the pages near the current one are built. pageCacheExtent (default 4) sets how many pages are kept on each side. Pages that are already built are reused when you turn, so a 600-page book costs about the same as a 10-page one. Raise the value if your pages are expensive to build and users flip fast. Lower it to save memory.

Migrating to 2.0

  • startPageIndex is read once. Changing it after the book is shown no longer navigates. Use jumpToPage or animateToPage.
  • PageFlipEvent.flip fires once per page change, after the turn completes. Its data is always the new page index as an int. It no longer fires at the start of nextPage with a Map.
  • onPageChanged fires once, with the new page. It used to fire twice per turn.
  • The controller no longer throws before a book is attached. Check hasClients. Getters return neutral values and navigation returns false.
  • Short back drags are cancelled in single-page mode instead of turning the page.
  • usePortrait is deprecated. Use pageViewMode.

The full list is in the changelog.

Troubleshooting

A button near a page corner doesn't respond

Corners are reserved for turning while flipOnTap is on. Set FlipSettings(flipOnTap: false).

Tapping a page turns it, but I only want drags

Same setting: flipOnTap: false.

My own onDoubleTap never fires

With zoom on, the book's double-tap zoom takes the gesture. Pass enableDoubleTapZoom: false.

White edges flash when turning dark pages

Set pageBackgroundColor to your page color.

The page doesn't move to startPageIndex after I change it

It is an initial value only. Use controller.jumpToPage.

A vertical list inside a page turns the page instead of scrolling

Raise swipeAngleThreshold so a drag must be more clearly horizontal to turn the page.

The PDF doesn't load

Make sure TurnablePdf.initPDFLoaders() runs before runApp, that asset PDFs are listed in pubspec.yaml, and that network URLs allow your app's origin on the web (CORS).
